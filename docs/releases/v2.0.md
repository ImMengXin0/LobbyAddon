# v2.0 · 大厅玩家样式管理

首个整理发布的版本，包含昵称、称号、后缀与聊天颜色的完整管理能力，以及带横幅的中文 README。

## 本次内容

- 昵称、称号与后缀的永久/临时设置，支持冷却、可见与原始长度限制、颜色权限、Unicode 规范化禁用词和按世界/子服限制。
- 聊天颜色系统：传统 16 色、Hex 单色、双端渐变与加粗/斜体/下划线/删除线/乱码，独立于聊天排列格式。
- 分层个人设置菜单与配置化预设菜单，自由文本从玩家下一条聊天输入读取。
- 可选审核流、持久化待审核申请，以及管理员审核与修改历史查询。
- YAML / MySQL 双存储；MySQL 使用 HikariCP，读写全异步，带缓存优先、失败重试与定时同步。
- 统一聊天、TabList 与可选原生记分板头顶名，`display.enabled: false` 可完整还原。
- PlaceholderAPI 占位符、BungeeCord 跨服人数缓存失效回退与子服状态。
- 禁言提示冷却、世界豁免与命令白名单。
- 整理 Gradle Wrapper 8.13、版本号、Git 忽略规则与发行素材。

## 安装与升级

环境要求：**Java 8+** 与 **Spigot / Paper 1.8.8** 及以上服务端；自定义称号与后缀需要 **LuckPerms**；PlaceholderAPI 与 TAB 为可选。

停服后将 `LobbyAddon-2.0.jar` 放入 `plugins/` 目录，启动一次让插件生成 `config.yml`，按需调整 `storage`、`mysql`、`display` 与限制配置后重启。使用 MySQL 时可临时开启 `mysql.migrate-yaml-on-first-load` 导入已有 `nicks.yml`，导入完成后必须恢复为 `false`。

升级时直接替换 JAR；已有配置不会被默认配置覆盖，缺少的配置键会在启动时补全。
